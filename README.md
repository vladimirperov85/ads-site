# Ads Site — сайт объявлений

Учебный проект сайта объявлений о продаже автомобилей на Django.
Пользователи регистрируются, публикуют объявления с фото, ищут и фильтруют
объявления по категории и бренду автомобиля, ставят лайки.

## Функциональность

- Регистрация, вход и выход пользователей
- Создание, редактирование и удаление объявлений
- Загрузка изображения к объявлению
- Категории автомобилей: седан, кроссовер, внедорожник
- Бренды автомобилей: Toyota, Honda, Ford, VW, BMW, Mercedes, Audi, Hyundai, KIA, LADA
- Фильтрация объявлений по категории и бренду
- Поиск по заголовку и описанию (регулярные выражения, без учёта регистра)
- Лайки объявлений
- Профиль пользователя со списком его объявлений

## Технологии

- Python 3
- Django 5.1
- PostgreSQL
- Pillow (работа с изображениями)
- python-dotenv (переменные окружения)

## Структура проекта
├── ads/ # приложение объявлений: модели, формы, представления
├── core/ # настройки проекта (settings, urls, wsgi)
├── templates/ # HTML-шаблоны
├── media/ # загруженные файлы (изображения объявлений)
├── manage.py
└── requirements.txt


## Установка и запуск

1. Клонируйте репозиторий:

  ```bash
   git clone https://github.com/vladimirperov85/ads-site.git
   cd ads-site
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/macOS
   source venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте базу данных PostgreSQL.

5. Создайте файл `.env` в корне проекта:

  ```
   SECRET_KEY=ваш_секретный_ключ
   DB_NAME=имя_базы
   DB_USER=пользователь
   DB_PASSWORD=пароль
   DB_HOST=localhost
  DB_PORT=5432
  ```

6. Примените миграции:

   ```bash
   python manage.py migrate
   ```

7. Создайте суперпользователя (для доступа к админке):

   ```bash
   python manage.py createsuperuser
   ```

8. Запустите сервер разработки:

   ```bash
   python manage.py runserver
   ```

9. Откройте в браузере: http://127.0.0.1:8000/
